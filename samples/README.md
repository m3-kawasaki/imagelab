# samples — 写真の置き場所

**このフォルダは空です。**画像ファイルは1枚も同梱していません。

## 同梱サンプルについて

ヘッダの「サンプル」に並んでいる9枚は、**このフォルダのファイルではなく、
`js/samples.js` がその場でコードから描いている合成チャート**です。
外部から画像を持ち込んでいないので、権利関係の確認が要りません。

| サンプル | 主な用途 |
|---|---|
| グレー階段＋ランプ | トーンカーブ、ガンマ補正 |
| 低コントラスト（暗部にディテール） | ヒストグラム平坦化 と CLAHE の比較 |
| 幾何図形（直線・円・斜線） | Sobel の勾配方向、Canny の段階表示 |
| ゾーンプレート | 平滑化の効き、エイリアシング |
| ソルト＆ペッパーノイズ | メディアン と ガウシアンの比較 |
| ガウシアンノイズ＋段差 | バイラテラル と ガウシアンの比較 |
| ぼけた細線・格子 | アンシャープマスク |
| ジーメンススター | 解像力、ぼけ量の測定 |
| カラーバー＋彩度グラデ | 点処理の「輝度のみ / RGB個別」の比較 |

## 自分の写真を使うとき

**ヘッダの［画像を開く］から選んでください。**画面へのドラッグ＆ドロップでも読み込めます。

読み込んだ画像はブラウザの中だけで処理され、**外部には一切送信されません。**
このフォルダに置く必要もありません（置き場所はどこでも構いません）。

### なぜ「サンプル」のプルダウンに自動で並ばないのか

`index.html` をダブルクリックして `file://` で開く使い方に対応しているためです。
ブラウザは `file://` 配下の画像を「別の出所のもの」として扱うので、
`<img src="samples/xxx.jpg">` のように読み込むと canvas が汚染（tainted）状態になり、
`getImageData()` で画素を取り出せなくなります。
ファイル選択やドラッグ＆ドロップで読み込んだ場合はこの制限がかからないので、
そちらの経路だけを用意しています。

（公開ページのように `https://` で開いた場合はこの制限が消えるので、
`samples/` の一覧をプルダウンに載せることは可能です。同梱の写真が無いので手つかずです。）

### どんな写真が向いているか

処理の効きが見えることが第一です。次のような素材が使えます。

- **白飛び・黒つぶれがある写真** … トーンカーブ、ガンマ補正、CLAHE
- **逆光で暗部が潰れた写真** … ヒストグラム平坦化 と CLAHE の差が出ます
- **高感度で撮ったノイズの多い写真** … バイラテラル、メディアン
- **細かいテクスチャ（布、木目、金網）** … 平滑化、アンシャープマスク
- **直線的な人工物（建物、看板）** … Sobel、Canny

長辺は 2000px 程度までで十分です。読み込み後は「作業解像度」で自動的に縮小されます。
